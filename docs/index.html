Discord Quest scanning and game activity queues, in one Windows app.

Orbs is an independent desktop utility for reviewing Discord Quests, organizing supported Play on Desktop tasks, and simulating local game presence. It's not an official Discord app, and Quest rewards are never guaranteed.

Read this before using Orbs.

Simulating completion of Discord Quests without completing the required activity is prohibited by Discord. Account restrictions are possible even with infrequent use. We recommend avoiding continuous or repeated sessions; waiting three days is only a conservative restraint, not a tested safe interval. The risk-free option is to complete Quests genuinely without using simulation. See safety and account-risk details.

What Orbs can do

Read visible Quests

Inspect loaded Discord Quest cards in the selected desktop client, distinguish supported desktop play tasks from review-only entries, and keep ambiguous titles visible.

Create timed queues

Arrange one game at a time, edit play-time targets and order, and retain unfinished local time if a session is interrupted. Local elapsed time is not verified Discord progress.

Simulate game presence

Provide supported local game activity through Discord's desktop client without launching the game. This may violate Discord's Quest policy, and does not guarantee server-side credit.

Select a Discord client

Use installed or running Discord Stable, PTB, or Canary, with selected-client binding during activity and scanning.

Use an English or Arabic interface

Orbs supports English and Egyptian Arabic. Discord's own UI currently needs to be in English for scanner navigation.

Update and keep local settings

Installed versions offer update checks, diagnostics, saved queues, preferences, and optional Windows sign-in setup.

How to get started

  1. Download the installer only from the official Orbs GitHub Releases page.
  2. Install and open Orbs; select your language and the Discord desktop client.
  3. Keep Discord's interface in English and open during scanning; don't navigate or scroll while the scanner runs.
  4. Review Quest requirements in Discord and use the queue controls only with an understanding of the policy and account risks.

The installer is unsigned and may trigger a Windows SmartScreen warning. Verify its origin; never disregard unexpected security warnings. Windows executable is prepackaged; no Python install is required.

Know the difference between Orbs and Discord Orbs

Discord Orbs are Discord's reward currency. Orbs (this app) is a separate third-party Windows program, maintained by Skandar. Orbs cannot guarantee rewards, isn't affiliated with Discord, and doesn't patch the Discord client or require an account token. Read frequently asked questions and the Quest-type guide.
