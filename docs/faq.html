Orbs for Discord: frequently asked questions

Straight answers to common questions about the independent Orbs Windows app, Discord Quests, game-presence simulation and account restrictions.

Safety and Discord rules

Is Orbs safe, undetectable or approved by Discord?

No. Orbs is a third-party utility not affiliated with or approved by Discord. Simulating Quest completion without performing the required activity violates Discord's Platform Manipulation Policy. Any use of simulation can result in restrictions; neither a local status nor an audit is proof of account safety.

Is waiting three days between sessions safe?

There is no verified safe frequency. The project's recommendation not to run continuously and to leave at least three days between optional sessions is only a conservative restraint; it cannot prevent detection or penalties. The safe way to avoid simulation-related account risk is to complete Quests genuinely.

Will using Orbs get me Discord Orbs automatically?

No guarantee. Discord Orbs are Discord's own reward currency, distinct from the Orbs app. Discord alone decides eligibility, actual Quest progress and rewards. Orbs' local simulated activity, timer and estimated statistics do not establish server-side credit.

Features and limitations

What does the Orbs scanner read?

It navigates the chosen desktop Discord client's visible Quests interface through Windows accessibility and reads loaded Quest cards. Unsupported, ambiguous, interactive and completed entries can be excluded from the playable desktop queue.

Do I need to install or launch the actual game?

Orbs' optional simulator aims to present local supported game presence without launching the game. This is distinct from actually playing and can violate Discord policy. For Quest compliance, launch the eligible real game and perform the activity required by the Quest.

Does it support video Quests, streams and Discord activities?

No. Videos, streams and in-Discord activities are not automatically completed. Some Quest objectives require specific genuine game or account actions. See the Quest type guide.

Does Orbs use my Discord token or patch the Discord client?

The desktop app doesn't require an account token and doesn't patch Discord itself. Its local presence mechanism doesn't make simulated Quest engagement authorized by Discord.

Does it work with Discord Canary or PTB?

It can select installed or running Discord Stable, PTB or Canary. Supported UI layouts and Quest detection can change with client updates.

Installation and updates

Where can I download Orbs for Windows?

Get the installer from JPEG111/orbs-release on GitHub, the project's designated public download page. The released Windows app doesn't require Python. The installer is unsigned, so assess any SmartScreen warning carefully.

Is Orbs open source?

No open-source claim is made. The public GitHub repository provides download information and documentation; the full source code is kept privately by the maintainer.

What if the scanner cannot see my Quests?

Keep the chosen Discord desktop client running, set its UI language to English, and avoid navigating or scrolling during the scan. Discord changes can still break compatibility. Review diagnostics through Orbs Settings and confirm Quest progress in Discord itself.

Can I disable automatic start?

Yes. Automatic mode is opt-in and may run a fresh scan at Windows sign-in if enabled. Disable it in Settings if you don't want repeated automated activity. One-click scan and start can also be disabled for scan-only control.
